# Mutelet

Muteletは、Apple Silicon搭載Macのメニューバーで使える、オープンソースのマイクミュートアプリです。

> Muteletは現在開発中です。署名・公証済みの初回リリースはまだ公開されていません。

[English](README.md)

## 主な機能

- Macで選択中のマイク、指定した1台、またはすべてのマイクをミュート
- どのアプリを使っていても、ショートカットを押している間だけ話せるプッシュトゥトーク（PTT）
- 機器のミュート機能と入力音量を併用し、ミュート機能がない場合は音量で代替
- Macで使うマイクの変更や機器の再接続に追従し、一部を操作できない場合も明示
- モード、対象のマイク、ショートカット、画面上の状態表示、ログイン時の起動を設定画面から変更
- Rosettaを使わずApple Silicon搭載Macで動作

Muteletは音声を録音せず、サーバーへの通信や利用状況データの収集も行いません。マイク、アクセシビリティ、入力監視の権限も要求しません。詳しくは[プライバシー](docs/PRIVACY.md)を参照してください。

## 動作環境

- Apple Silicon Mac
- macOS 14 Sonoma以降

## ソースから起動する

最新の安定版Xcodeをインストールして、次を実行します。

```bash
git clone <repository-url>
cd mutelet
open Mutelet.xcodeproj
```

`Mutelet`スキームを選び、**My Mac**で実行します。Dockには表示されず、メニューバーにマイクのアイコンが現れます。

コマンドラインで一式を検証する場合:

```bash
swift test
./scripts/verify.sh
```

`verify.sh`の生成物は`.build/`内に置かれ、配布用の署名は行いません。macOSで実行するため、UIテスト用ホストとRunnerだけをad-hoc署名します。
普段使っているMuteletを中断しないよう、通常実行ではUIテストをビルドだけ行います。ローカルでUIテストも実行するときはMuteletを終了して`RUN_UI_TESTS=1 ./scripts/verify.sh`を実行してください。CIでは毎回実行します。

## 使い方

初期ショートカットは **Control + Shift + M** です。

- **トグル:** 1回押すとミュートし、もう1回押すと直前の状態へ戻します。
- **プッシュトゥトーク:** 待機中はミュートされます。話している間だけショートカットを押し続け、離すと再びミュートされます。

メニューバーからモードと対象のマイクを選択できます。**設定…** ではショートカット、画面上の状態表示、ログイン時の起動も変更できます。

機器にミュート機能がない場合は、操作可能な入力音量を0にして消音することがあります。機器やソフトウェアによってはこの制御を迂回できるため、完全に消音できるとは限りません。その場合は警告を表示します。詳しくは[対応機器](docs/DEVICE_COMPATIBILITY.md)を参照してください。

## 仕組み

MuteletはCore Audioの制御用プロパティを直接操作し、音声ストリームを開きません。音量でミュートする場合は、変更前の値を機器UIDとチャンネルごとに保存し、ミュート解除時に復元します。

## よくある質問

### マイクに警告が表示されるのはなぜですか？

機器に音量調節しかない、操作可能な制御がない、接続が切れている、または複数のマイクの一部だけ操作に失敗した可能性があります。Muteletはこれらを、確実にミュートできた状態と区別して表示します。

### プッシュトゥトークへ切り替えるとすぐミュートされるのはなぜですか？

待機中のマイクを確実にミュートするためです。話す間だけショートカットを押し続けてください。キーを離すと再度ミュートします。スリープへ移行するときも可能な範囲でミュートし、Muteletの終了時には処理の完了を待ちます。

### 特別な権限は必要ですか？

必要ありません。MuteletはCore Audioプロパティを操作し、Carbonのグローバルホットキーを登録します。イベントタップやマイク音声の取得は行いません。
