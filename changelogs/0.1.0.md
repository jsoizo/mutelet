# Mutelet 0.1.0

The first preview of Mutelet, an Apple Silicon-native microphone mute utility for the macOS menu bar.

## Highlights

- Toggle mute or hold a shortcut to talk.
- Target the system default input, one selected device, or every input.
- Restore volume-based input controls to their previous values.
- Configure the shortcut, mode, target, HUD, and launch at login.
- English and Japanese interface.

## Requirements

- Apple Silicon Mac
- macOS 13 Ventura or later

## Known limitations

- A volume-only input cannot provide the same guarantee as a native hardware mute.
- Device behavior varies; the initial compatibility list depends on community and maintainer testing.
- The app does not update itself in v1.
