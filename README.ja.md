# Mutelet

Muteletは、Apple Silicon搭載Macのメニューバーで使える、オープンソースのマイクミュートアプリです。

[English](README.md)

## 主な機能

- Macで選択中のマイク、指定した1台、またはすべてのマイクをミュート
- どのアプリを使っていても、ショートカットを押している間だけ話せるPush to Talk（PTT）
- Push to Talkで音が入りうる間、画面の縁を光らせて表示（HUDの代わり）
- 機器のミュート機能と入力音量を併用し、ミュート機能がない場合は音量で代替
- Macで使うマイクの変更や機器の再接続に追従し、一部を操作できない場合も明示
- トグルとPush to Talkそれぞれのショートカット、モード、対象のマイク、画面上の状態表示、ログイン時の起動を設定画面から変更
- Rosettaを使わずApple Silicon搭載Macで動作

Muteletは音声を録音せず、サーバーへの通信や利用状況データの収集も行いません。マイク、アクセシビリティ、入力監視の権限も要求しません。詳しくは[プライバシー](docs/PRIVACY.md)を参照してください。

## 動作環境

- Apple Silicon Mac
- macOS 14 Sonoma以降

## ダウンロード

Mutelet 1.0.0は、どちらの配布元からも無料で利用できます。

- [Mac App Store](https://apps.apple.com/jp/app/id6826858511)：インストールと更新はApp Storeから行います。
- [GitHub Releases](https://github.com/jsoizo/mutelet/releases/latest)：署名・公証済みのDMGをダウンロードし、開いてMuteletをアプリケーションフォルダへドラッグします。更新するときはMuteletを終了し、新しい版で置き換えます。リリースページにはSHA-256チェックサムも掲載しています。

### 配布元を切り替える

1. Muteletでミュートしたマイクを元の状態に戻し、起動中のMuteletをすべて終了します。
2. 別の配布元から同じか新しいバージョンを入手し、アプリケーションフォルダ内の既存のアプリを置き換えます。インストール先は1か所にし、別の場所にあるコピーを同時に起動しないでください。
3. Muteletを開き、対象のマイク、モード、ショートカット、画面表示の設定を確認します。ショートカットの動作も確認してください。ログイン時に起動しなくなった場合は、設定で一度オフにしてからオンにし、macOSのシステム設定で許可を確認します。

設定とマイクの制御値を復元するためのデータはMac内に保存しています。切り替え時に削除しないでください。古いバージョンへの切り替えはサポートしていません。保存された設定の形式を読み取れない場合、古い版では設定が初期化されることがあります。

## ソースから起動する

最新の安定版Xcodeをインストールして、次を実行します。

```bash
git clone https://github.com/jsoizo/mutelet.git
cd mutelet
./scripts/build.sh
open .build/DerivedData/LocalBuild/Build/Products/Release/Mutelet.app
```

Dockには表示されず、メニューバーにマイクのアイコンが現れます。

`build.sh`はローカル用のRelease版を`.build/`内に生成します。配布用の署名は行いません。

## 使い方

初期ショートカットは、トグルが **Control + Shift + M**、Push to Talkが **F8** です。

- **トグル:** 1回押すとミュートし、もう1回押すと直前の状態へ戻します。
- **Push to Talk:** 待機中はミュートされます。話している間だけショートカットを押し続け、離すと再びミュートされます。

メニューバーからモードと対象のマイクを選択できます。**設定…** ではモードごとのショートカット、画面上の状態表示、ログイン時の起動も変更できます。

機器にミュート機能がない場合は、操作可能な入力音量を0にして消音することがあります。機器やソフトウェアによってはこの制御を迂回できるため、完全に消音できるとは限りません。その場合は警告を表示します。詳しくは[対応機器](docs/DEVICE_COMPATIBILITY.md)を参照してください。

## 仕組み

MuteletはCore Audioの制御用プロパティを直接操作し、音声ストリームを開きません。音量でミュートする場合は、変更前の値を機器UIDとチャンネルごとに保存し、ミュート解除時に復元します。

## よくある質問

### マイクに警告が表示されるのはなぜですか？

機器に音量調節しかない、操作可能な制御がない、接続が切れている、または複数のマイクの一部だけ操作に失敗した可能性があります。Muteletはこれらを、確実にミュートできた状態と区別して表示します。

### Push to Talkへ切り替えるとすぐミュートされるのはなぜですか？

待機中のマイクを確実にミュートするためです。話す間だけショートカットを押し続けてください。キーを離すと再度ミュートします。スリープへ移行するときも可能な範囲でミュートし、Muteletの終了時には処理の完了を待ちます。

### 特別な権限は必要ですか？

必要ありません。MuteletはCore Audioプロパティを操作し、Carbonのグローバルホットキーを登録します。イベントタップやマイク音声の取得は行いません。登録されたファンクションキーはMuteletが消費するため、前面アプリへは渡りません。
