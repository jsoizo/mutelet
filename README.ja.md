# Mutelet

Muteletは、macOSのメニューバーから使える、Apple Siliconネイティブのオープンソース・マイクミュートアプリです。

> Muteletは現在開発中です。署名・公証済みの初回リリースはまだ公開されていません。

[English](README.md)

## 主な機能

- システム既定入力、選択した1台、またはすべての入力をミュート
- グローバルショートカットを押している間だけ話せるPush to Talk
- 書き込み可能なnative muteと入力音量を併用し、native muteがない場合は音量のみでフォールバック
- 既定入力の変更や機器の再接続へ追従し、部分的な失敗も明示
- モード、対象、ショートカット、HUD、ログイン起動を設定画面から変更
- Rosettaを使わずApple Silicon上でネイティブ動作

Muteletは音声を録音せず、サーバーへの通信やテレメトリも行いません。マイク、アクセシビリティ、入力監視の権限も要求しません。詳しくは[プライバシー](docs/PRIVACY.md)を参照してください。

## 動作環境

- Apple Silicon Mac
- macOS 13 Ventura以降

## ソースから起動する

最新の安定版Xcodeをインストールして、次を実行します。

```bash
git clone <repository-url>
cd mutelet
open Mutelet.xcodeproj
```

`Mutelet`スキームを選び、**My Mac**で実行します。Dockには表示されず、メニューバーにマイクのアイコンが現れます。

コマンドラインで一式を検証する場合:

```bash
swift test
./scripts/verify.sh
```

`verify.sh`の生成物は`.build/`内に置かれ、配布用の署名は行いません。macOSで実行するため、UIテスト用ホストとRunnerだけをad-hoc署名します。
普段使っているMuteletを中断しないよう、通常実行ではUIテストをビルドだけ行います。ローカルでUIテストも実行するときはMuteletを終了して`RUN_UI_TESTS=1 ./scripts/verify.sh`を実行してください。CIでは毎回実行します。

## 使い方

初期ショートカットは **Control + Shift + M** です。

- **Toggle:** 1回押すとミュートし、もう1回押すと直前の状態へ戻します。
- **Push to Talk:** 待機中はミュートされます。話している間だけショートカットを長押しし、離すと再びミュートされます。

メニューバーからモードと対象入力を選択できます。**設定…** ではショートカット、HUD、ログイン起動も変更できます。

native muteを持たない機器では、書き込み可能な入力音量をゼロにして無音化する場合があります。機器やソフトウェアによってはこの制御を迂回できるため、完全なミュートを保証せず警告として表示します。詳しくは[対応機器](docs/DEVICE_COMPATIBILITY.md)を参照してください。

## 仕組み

MuteletはCore Audioのコントロールプロパティを直接操作し、音声ストリームを開きません。音量でミュートする場合は、変更前の値を機器UIDとチャンネルごとに保存して安全に復元します。

MuteletはMuteKeyのような従来のユーティリティが提供していた便利な操作体験に着想を得た独立実装です。公式な後継・互換配布物ではなく、コード、画像、名称、ブランド資産を流用しません。また、Intel時代のユーティリティが担っていた役割を、小さく保守可能なネイティブOSSとして置き換えるという点で、[Tiley](https://github.com/yusuke/tiley)のアプローチも参考にしています。

## よくある質問

### 入力に警告が表示されるのはなぜですか？

音量制御しか持たない、書き込み可能な制御がない、切断中、または複数入力の一部だけ操作に失敗した可能性があります。Muteletはこれらを、確認済みのミュート状態とは区別して表示します。

### Push to Talkへ切り替えるとすぐミュートされるのはなぜですか？

待機中の安全な状態にするためです。話す間だけショートカットを長押ししてください。キーを離すと再度ミュートします。スリープ通知時にはベストエフォートでミュートを要求し、終了時には処理完了を待ちます。

### 特別な権限は必要ですか？

必要ありません。MuteletはCore Audioプロパティを操作し、Carbonのグローバルホットキーを登録します。イベントタップやマイク音声の取得は行いません。
